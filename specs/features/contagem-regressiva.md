# Contagem regressiva

## Objetivo

Mostrar quantos dias faltam para o casamento.

## Usuario principal

Noivos e convidados.

## Comportamento esperado

- Calcular a diferenca entre a data atual e a data do casamento.
- Exibir dias restantes na pagina publica e no painel.
- Tratar o dia do casamento com uma mensagem especial.
- Tratar datas passadas sem erro visual.

## Criterios de aceitacao

- Dado uma data futura, quando a pagina carregar, entao deve exibir a quantidade de dias restantes.
- Dado que hoje seja a data do casamento, quando a pagina carregar, entao deve exibir uma mensagem de celebracao do dia.
- Dado uma data passada, quando a pagina carregar, entao nao deve exibir numero negativo como estado principal.

## Fora do escopo inicial

- Contagem com horas, minutos e segundos.
- Animacoes complexas.
