# Convite digital

## Objetivo

Gerar uma experiencia de convite compartilhavel por link.

## Usuario principal

Noivos e convidados.

## Comportamento esperado

- Disponibilizar um link publico do casamento.
- Permitir compartilhar o link pelo WhatsApp.
- Exibir as informacoes essenciais do evento.
- Levar o convidado para a confirmacao de presenca.

## Criterios de aceitacao

- Dado um casamento publicado, quando os noivos copiarem o link, entao o link deve abrir a pagina publica do casal.
- Dado um celular com WhatsApp, quando o usuario tocar em compartilhar, entao deve abrir uma mensagem pre-preenchida com o link do convite.
- Dado um convidado que acessa o convite, quando tocar em confirmar presenca, entao deve ser levado ao formulario de confirmacao.

## Fora do escopo inicial

- Convites individuais com nomes personalizados.
- Controle de acesso por senha.
- Rastreamento de abertura do convite.
