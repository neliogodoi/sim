# Pagina do casal

## Objetivo

Apresentar o casamento em uma pagina publica, bonita e simples, reunindo as informacoes principais para os convidados.

## Usuario principal

Convidado.

## Comportamento esperado

- Exibir nomes dos noivos.
- Exibir foto principal ou imagem de capa.
- Exibir data do casamento.
- Exibir mensagem curta dos noivos.
- Exibir atalhos para confirmacao de presenca, localizacao, agenda, presentes e album compartilhado.
- Aplicar o padrao visual definido em [Padrao visual](../visual-standard.md).
- Adaptar layout para celular e desktop.

## Criterios de aceitacao

- Dado um casamento configurado, quando o convidado acessar o link publico, entao deve ver nomes, data e mensagem do casal.
- Dado que nao exista imagem de capa, quando a pagina carregar, entao deve usar uma apresentacao visual padrao sem quebrar o layout.
- Dado um celular, quando a pagina for aberta, entao as acoes principais devem ser acessiveis sem zoom horizontal.

## Fora do escopo inicial

- Multiplos templates visuais.
- Dominio personalizado por casal.
- Galeria completa de fotos.
