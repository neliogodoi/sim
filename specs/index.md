# Especificacoes do MVP

## SIM - Seu Incrivel Momento

SIM e uma PWA em Angular para gerenciamento basico de casamento. O sistema usa Firebase como unica camada de backend para autenticacao, persistencia de dados e armazenamento de arquivos quando necessario.

## Objetivo do MVP

Permitir que os noivos criem um espaco digital simples para apresentar informacoes do casamento, compartilhar o convite, receber confirmacoes de presenca, organizar convidados e manter dados essenciais do evento em um painel administrativo.

## Criterio geral de pronto

O MVP sera considerado pronto quando os noivos conseguirem configurar os dados principais do casamento, compartilhar um link publico, receber confirmacoes de presenca e acompanhar os convidados confirmados pelo painel administrativo.
