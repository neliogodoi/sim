# Orientações da documentação

- Escreva em português e use caminhos relativos para navegar entre documentos e código.
- O README principal é o índice. Ao adicionar um guia, inclua um link nele e um caminho de volta no guia.
- Descreva comportamento observado no código separadamente de propostas, especificações antigas e limitações.
- Não copie tokens, valores de `.env`, dados de convidados ou configurações privadas para exemplos.
- Registre comandos disponíveis de verdade; não apresente teste, emulador ou backend ausente como implementado.
- Confira links locais e rotas antes de concluir. Markdown puro não exige build nem chamadas a serviços remotos.
